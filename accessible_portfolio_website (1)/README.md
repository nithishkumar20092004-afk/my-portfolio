# Accessible Personal Portfolio

This is a static, multi-page portfolio created for an HTML5 semantic structure and accessibility assignment.

## Files
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Contact form
- `styles.css` — Responsive styling
- `script.js` — Navigation, validation and dynamic year

## Accessibility features
- Semantic HTML5 landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Skip-to-content link
- Keyboard-visible focus states
- Accessible navigation with `aria-label`, `aria-current`, `aria-expanded`, and `aria-controls`
- Proper form labels and required-field handling
- Inline validation with `role="alert"` and live status messaging
- Responsive layout
- Reduced-motion support
- Descriptive page titles and meta descriptions

## Before submitting
1. Replace every `Your Name` with your real name.
2. Update project text with your own work if required.
3. Open `index.html` locally and test every navigation link.
4. Run Lighthouse in Chrome DevTools and check Accessibility and SEO.
5. Deploy the folder using GitHub Pages, Netlify, or another static host.
6. Submit the deployed HTTPS URL.

## Important
The contact form currently validates in the browser but does not send email. A real submission backend/form service must be connected if the assignment requires actual message delivery.
